# ---- Foundry Local runtime -------------------------------------------------
# IMPORTANT: this package resolves to two different libraries depending on CPU
# architecture, and they do not share an API.
#
#   arm64 (Apple Silicon)  -> 1.2.x  native SDK, bundles the inference runtime
#                             (foundry-local-core, onnxruntime-genai-core).
#                             No Homebrew `foundrylocal` install is needed.
#   x86_64                 -> 0.5.x  thin HTTP client for a separately
#                             installed service. Completely different calls.
#
# This project targets the 1.x API (`FoundryLocalManager.initialize`,
# `catalog.get_model`, `model.get_embedding_client`). The floor is therefore
# >=1.2 rather than >=0.5: pip on an x86_64 interpreter will fail to resolve it,
# which is the correct outcome - installing 0.5.x would satisfy the requirement
# and then break at the first call. Anaconda's Python is usually x86_64, so on
# a Mac use /opt/homebrew/bin/python3.12 to create the venv. See docs/07.
foundry-local-sdk>=1.2
# Generation goes through the OpenAI-compatible local web service, because the
# native chat client exposes no temperature/max_tokens. See runtime/foundry.py.
